## 🔒 Protection

Les fichiers de ce dépôt sont des **`.enc` chiffrés (AES-256)**. Ils sont **inutilisables tels quels** :
ils ne se lisent et ne s'exécutent **qu'avec le plugin `CoreOxoSK`** et une **licence valide** liée à ton serveur.

- Chiffrement **AES-256** du code
- **Licence en ligne** vérifiée au démarrage (révocable)
- Chargement en mémoire, aucun `.sk` en clair sur le serveur

Télécharger un `.enc` ne donne donc **aucun accès au code source**.

---

## 🚀 Installation

1. Procure-toi le plugin **CoreOxoSK** et ta **clé de licence** sur la [boutique](https://skript-sk.oxolion.link).
2. Mets `CoreOxoSK.jar` dans `plugins/` de ton serveur (Skript + skript-reflect requis).
3. Démarre une fois, colle ta clé dans `plugins/CoreOxoSK/config.yml`.
4. Place tes `.enc` dans `plugins/CoreOxoSK/encrypted/`, redémarre : tes scripts autorisés se chargent.

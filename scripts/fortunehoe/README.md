# Fortune Hoe

**Prix :** 1,49 EUR

Rend enfin l'enchantement Fortune utile sur les houes : récoltes et graines bonus en cassant des cultures mûres (blé, carottes, pommes de terre, betteraves, verrues du Nether). Chance et bonus entièrement réglables.

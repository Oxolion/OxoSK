# Deplacer les coffres pleins

**Prix :** 1,99 EUR

Déplace un coffre avec tout son contenu : accroupi + clic droit main vide pour le ramasser, repose-le pour tout restaurer. Gère les coffres doubles et intègre une solide protection anti-perte et anti-duplication.

---

Script protege OxoSK, chiffre et charge par le plugin CoreOxoSK. Fichier : `deplacer-coffres.enc`.

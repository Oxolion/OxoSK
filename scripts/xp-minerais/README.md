# XP sur minerais

**Prix :** Gratuit

Donne de l'XP en minant les minerais qui n'en lâchent pas en vanilla : fer, or, cuivre et débris antiques. Quantités réglables par minerai et option de blocage au Toucher de soie.

---

Script protege OxoSK, chiffre et charge par le plugin CoreOxoSK. Fichier : `xp-minerais.enc`.

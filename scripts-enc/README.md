# Fichiers chiffrés (.enc)

Dépose ici les fichiers `.enc` générés par `/oxosk encrypt` sur ton serveur de dev.

Ils sont **chiffrés en AES-256** : impossibles à lire ou exécuter sans le plugin
**CoreOxoSK** et une licence valide. Les publier ici ne révèle aucun code source.

> Le vrai code `.sk` n'est **jamais** mis dans ce dépôt public.
